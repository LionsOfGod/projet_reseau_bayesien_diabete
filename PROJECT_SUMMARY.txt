IMPLEMENTATION DETAILS
================================================================================

MODULES CLES
============

1. preprocessing.py (DataPreprocessor)
   - load_data(): Charge le CSV
   - handle_missing_values(): Détecte les 0 manquants
   - impute_missing_values(): Impute par la médiane
   - discretize_*(): Discrétise chaque variable (3 catégories)
   - preprocess(): Pipeline complet

2. network.py (BayesianNetwork)
   - NODES: 9 variables
   - EDGES: 8 arcs causaux
   - is_acyclic(): Vérifie l'acyclicité du DAG
   - topological_sort(): Ordre causal

3. cpt.py (CPTEstimator)
   - estimate_cpt(): Estime P(X|Parents) avec lissage Laplace
   - build_all_cpts(): Construit toutes les CPT
   - Lissage: (count + 1) / (total + k)

4. inference.py (BayesianInference)
   - joint_probability(): P(observation complète)
   - posterior_probability(): P(Outcome|obs)
   - predict(): Prédiction binaire avec seuil 0.5
   - explain_prediction(): Explication locale

5. evaluation.py (Evaluator)
   - Matrice de confusion (TP, FP, TN, FN)
   - Précision, Rappel, F1-Score
   - Exactitude, Spécificité
   - ROC-AUC

6. data_split.py (DataSplitter)
   - train_test_split(): 80/20 split
   - stratified_split(): Maintient proportions des classes
   - cross_validation_split(): k-fold CV

7. dependency_analysis.py (DependencyAnalyzer)
   - chi_square_test(): Test d'indépendance
   - analyze_all_pairs(): Analyse exhaustive

PIPELINE D'EXECUTION
================================================================================

main.py exécute 7 étapes:

1. PREPROCESSING
   └─ Charger → Nettoyer → Discrétiser

2. NETWORK DEFINITION
   └─ Définir DAG → Vérifier acyclicité

3. DATA SPLITTING
   └─ 80% train / 20% test (random_state=42)

4. CPT ESTIMATION
   └─ Calculer P(Xi|Parents) pour chaque nœud

5. INFERENCE & PREDICTIONS
   └─ Pour chaque test obs: calculer P(Outcome|obs)

6. EVALUATION
   └─ Confusion matrix, F1, ROC-AUC

7. EXPLANATIONS
   └─ Afficher 3 exemples avec explications locales

================================================================================
STRUCTURE DU RESEAU BAYESIEN
================================================================================

NODES (9):
  Pregnancies, Glucose, BloodPressure, SkinThickness, Insulin,
  BMI, DiabetesPedigreeFunction, Age, Outcome

EDGES (8):
  Pregnancies → Age
  SkinThickness → Insulin
  SkinThickness → BMI
  Glucose → Insulin
  Glucose → Outcome
  BMI → Outcome
  Age → Outcome
  Insulin → Outcome

DISCRETIZATION STATES (3 catégories chacun):
  Glucose: Faible (< 100), Intermediaire (100-125), Eleve (≥ 126)
  BMI: Faible (< 25), Normal (25-29), Eleve (≥ 30)
  Age: Jeune (< 30), Intermediaire (30-39), Eleve (≥ 40)
  ... etc
